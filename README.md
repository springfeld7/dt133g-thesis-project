## Overview

This project studies the robustness and fragility of state-of-the-art code language models fine-tuned to predict whether a code sample was authored by a human or generated by a machine. We build a reproducible pipeline that applies incremental, semantics-preserving stylistic transformations to code, measure attribution decay across datasets, languages and models, and produce vulnerability curves and empirical thresholds for attribution failure. The repository contains training and evaluation code, transformation tooling, dataset references, and Jupyter notebooks to reproduce experiments and generate the figures reported in the thesis.

## Installation

1. Clone the repository
    ```bash
    git clone https://github.com/springfeld7/dt133g-thesis-project.git
    cd dt133g-thesis-project
    ```

2. Install dependencies:
	- **A. Using [uv](https://github.com/astral-sh/uv) (recommended):**
		```sh
        # Create a Python virtual environment and install the project
		uv sync
		# If you want to skip dev dependencies:
		uv sync --no-dev
		```
	> Note:	uv will automatically create and manage a virtual environment for you.
	- **B. Using pip:**
        ```sh
        # Create and activate a Python virtual environment
        python -m venv .venv
        .venv\Scripts\activate  # Windows
        source .venv/bin/activate  # Linux/Mac

		# Install the project in editable mode
		pip install -e .
		```
